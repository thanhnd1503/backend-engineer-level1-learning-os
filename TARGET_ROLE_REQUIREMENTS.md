
# Target Role Requirements — Backend Software Engineer Level I

## Purpose

Translate the target role into skills that can be learned, demonstrated, and assessed. This is a preparation matrix, not a claim that every listed topic is an official hiring requirement.

The current known role description emphasizes:
- high-quality, mission-critical software;
- working with product/design partners and owning features end-to-end;
- participation in code reviews and architecture discussions;
- using AI-assisted development workflows while validating generated output;
- a managed programming language such as Java, Scala, Go, C#, or a comparable language;
- relevant software development experience or a coding bootcamp pathway.

Review this file periodically against current, verifiable sources. Mark each item as:
- **Preparation target** — included to prepare for likely Level I engineering work;
- **Unverified** — not yet checked against a cited, current source.

## Evidence rules

For every competency, record:
1. current level: Not assessed / Fail / Partial / Pass;
2. evidence link or artifact;
3. assessment date;
4. what the learner could do independently;
5. remaining gap.

Do not use "familiar with" as a substitute for demonstrated ability.

## CV mapping

Only add:
- professional skills that were used in actual employment;
- learning-project skills clearly labeled as project experience;
- measurable outcomes that can be verified;
- proficiency descriptions consistent with assessment evidence.

Never present CareerBank as employment experience.
